#Fake News Detection System-Veritas AI 🛡️🤖

Veritas AI is a Machine Learning-based application designed to identify and classify misinformation (Fake News) using Natural Language Processing (NLP).

## 🚀 Overview
In today's digital age, the spread of fake news is a major concern. This project aims to build a reliable model that analyzes the linguistic features of news articles to determine whether they are "Real" or "Fake."

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **Libraries:** Pandas, NumPy, Scikit-learn, NLTK
- **Vectorization:** TF-IDF Vectorizer
- **Algorithms:** RandomForestClassifier 
- **Frontend:** HTML, CSS (Flask)

## 📊 Dataset
The model is trained on a labeled dataset containing thousands of news articles. 
> **Note:** Due to the large size of the original CSV file, it is not uploaded here. You can access the dataset [https://www.kaggle.com/datasets/emineyetm/fake-news-detection-datasets].
